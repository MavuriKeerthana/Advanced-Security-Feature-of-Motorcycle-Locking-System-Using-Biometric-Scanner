# Advanced Security Feature of Motorcycle Locking System Using Biometric Scanner

## Project Overview
This project is a biometric-based motorcycle security system that uses fingerprint authentication to control vehicle access. Only authorized users whose fingerprints are stored in the system can unlock and start the motorcycle.

## Objectives
- Enhance motorcycle security
- Prevent unauthorized access
- Provide biometric authentication using fingerprints

## Technologies Used
- Arduino Uno
- Fingerprint Sensor Module
- Relay Module
- Embedded C / Arduino IDE

## Features
- Fingerprint enrollment
- Fingerprint verification
- Secure motorcycle locking system
- User authentication before ignition

## Repository Contents
- Thesis.pdf – Project report
- Enrollment Code – Fingerprint registration program
- Bike Starting Code – Fingerprint verification and ignition control

## Future Enhancements
- GSM alerts for unauthorized access
- Mobile application integration
- GPS tracking system
